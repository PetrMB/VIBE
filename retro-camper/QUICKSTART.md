# 🚀 Rychlý Start

## Spuštění hry (3 kroky)

### 1. Otevři terminál v této složce

```bash
cd retro-camper
```

### 2. Spusť lokální server

**Python 3:**
```bash
python -m http.server 8000
```

**Python 2:**
```bash
python -m SimpleHTTPServer 8000
```

**Node.js:**
```bash
npx http-server -p 8000
```

**PHP:**
```bash
php -S localhost:8000
```

### 3. Otevři prohlížeč

Jdi na: **http://localhost:8000**
